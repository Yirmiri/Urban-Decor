## Wrapping It Up Part II || v1.2.0 MC-1.21.1

### Breaking Changes (breaks on Fabric only)
- Changed the name and id of "plastic_desk_table" to "plastic_table"

### Additions
- Added Cash Registers, can be wrapped
- Added Vending Machines

### Changes
- Clocks now have a small spring movement when ticking
- Grandfather Clocks now play their chime further away
- Grandfather Clocks no longer play chime if there is a #dampens_vibrations block under it (anything that dampens Sculk Sensors)
- Dyed Plastic Lights now appear in the creative inventory

### Tweaks
- Updated sounds of most blocks
- Improved position of Sinks in inventory
- Removed Urban Decor advancements

### Recipe Updates
- Porcelain, Porcelain (from quartz), Stainless Steel Ingot, and Polypropylene recipes are now shapeless
- Stainless Steel Ingot now outputs x4 instead of x2
- Steel Pipes now require x1 additional Stainless Steel Nugget and x1 less Stainless Steel Ingot
- Steel Pipes now output x6 instead of x8
- Porcelain Block now outputs x4 instead of x1
- Removed Checkered Porcelain Tiles from Porcelain recipe
- Porcelain now requires x2 Clay Ball and 2x Sand instead of x3 Clay Ball and x1 Flint both for an output of x8
- Porcelain from Quartz now outputs x12 instead of x8
- Dark Porcelain now requires x2 Porcelain and x2 Chromite for an output of x4 instead of x8 Porcelain and x1 Chromite for an output of x8
- Polypropylene now requires x2 Coal and x3 Polyanthous instead of x2 Coal, x1 Clay Ball, and x1 Polyanthous
- Toolbox now requires x2 Stainless Steel Ingot and x1 Stainless Steel Nugget instead of x8 Stainless Steel Ingots
- Filing Cabinet no longer requires x1 Chest
- Cupboard no longer requires x1 Chest
- Toilet Paper requires x1 Steel Pipe instead of x1 Stick (still additionally requires x8 Paper)
- Bathtubs now require x5 Porcelain instead of x4 Porcelain and x3 Porcelain Blocks
- Dryer now requires x1 additional Glass
- Fridges and Freezers now require Steel Pipes instead of Packed Ice
- Oven no longer requires x1 Smoker and now require x1 Coal instead of x1 Redstone
- Stoves now require x3 Stainless Steel Ingots instead of x2 Stainless Steel Ingots and x1 Magma Block
- Toasters now require x2 Stainless Steel Ingots, x3 Stainless Steel Nuggets, and x1 Coal instead of x2 Stainless Steel Ingots, x2 Stainless Steel Nuggets, x1 Redstone, and x1 Magma Block
- Microwaves now require x6 Stainless Steel Ingots and x2 Stainless Steel Nuggets rather than x4 Stainless Steel Ingots and x4 Redstone
- Trash Can now outputs x2 instead of x1
- Desk Fan now outputs x3 instead of x1
- Floor Lamps now outputs x3 instead of x1 and had x2 Stainless Steel Ingots replaced with x2 Steel Pipe and x1 Glowstone replaced with x1 Glowstone Dust
- Plastic Chair now outputs x4 instead of x1
- Stainless Steel Chair now outputs x4 instead of x1
- Plastic Table now outputs x4 instead of x2 and had x1 Stainless Steel Ingots replaced with x1 Steel Pipe
- Wall Clock now requires x4 Polypropylene and x1 Redstone instead of x8 Polypropylene and x1 Clock
- Grandfather Clocks had x1 Clock replaced with x1 Redstone
- Wooden Box now outputs x8 instead of x1
- Air Conditioners now require x1 Redstone instead of x1 Wind Charge and require x2 less Steel Pipes
- Radiator now outputs x4 instead of x1 and requires x4 Steel Pipes and x2 Redstone instead of x4 Steel Pipes, x2 Stainless Steel Ingots, and x1 Blaze Rod
- Wraps now output x6 instead of x3
- Towel Bar now outputs x3 instead of x1
- Picture Frames output x4 instead of x1 but now require x4 Polypropylene and x1 Paper instead of x8 Stick and x1 Paper
- Plastic Lights output x8 instead of x12 but now require x2 Polypropylene, x1 String, and x1 Glowstone Dust instead of x3 Polypropylene and x3 Glowstone Dust
- Towels now output x4 instead of x2
- Rigid Glass now outputs x8 instead of x3, but requires x2 Glass and x4 Stainless Steel Nuggets instead of x3 Glass Pane and x6 Stainless Steel Nuggets
- Cupboards now output x6 instead of x1
- Filing Cabinets now output x4 instead of x1
- Turbines now output x4 instead of x1

### Fixes
- Fixed Steel Pipes being replaceable with other blocks
- Fixed multiple Plastic Lights being unable to exist on the same block despite being a multiface block
- Fixed only one instance of Grandfather Clock playing chimes
