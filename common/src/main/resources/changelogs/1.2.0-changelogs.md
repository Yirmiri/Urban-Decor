## Wrapping It Up Part II || v1.2.0 MC-1.21.1

### Breaking Changes (breaks on Fabric only)
- Changed the name and id of "plastic_desk_table" to "porcelain_table"

### Dolls
- Dolls are a new decorative that can be crafted with the newly added Mattress material
- Dolls have toolbox variants that can set their pose
- Dolls have can have different textures despite all being the same block
- Dolls can be placed on the player's head armor slot to display it ontop of their head
- Added Sewing Machine, Sewing Machines are a new block made of Polypropylene and let you choose the Doll's texture
- Added Sewing Needles, Sewing Needles can create specific types of Dolls when they have a `doll_texture` data component

- [For Datapacks & Developers] You can easily create your own Dolls with a datapack but creating a json of any name at `data/<modid>/dolls/<name>.json`
  - `resource_location` Points to the texture used for the Doll (example: `"urban_decor:textures/entity/doll/yirmiri.png"`)
  - `requires_needle` If set to true, crafting this Doll at the Sewing Machine will require a Sewing Needle with a matching `doll_texture` data component
  if this is false it will always be craftable in the Sewing Machine
  - ...then place your Doll texture in the directory path that was specified in the file's `resource_location`
  - Feel free to look at the default dolls in `data/urban_decor/dolls/...` to use as examples, additionally there is a template Doll
  texture at `assets/urban_decor/textures/entity/doll/template.png`
